# Ponytail Gain

Display this boundary when invoked. One-shot: do not change mode, write files,
or persist anything.

```
Ponytail favors smaller, more direct solutions when they still meet the
requirements. It does not claim a fixed code, cost, or speed improvement.

This repository: use ponytail-debt to list documented deferrals, or
ponytail-audit to identify complexity worth investigating.
```

## Honesty boundary

Never print a savings number for a repository without a defined baseline and a
reproducible measurement. A counted debt ledger is not a measure of code, cost,
or speed saved.

## Boundaries

One-shot display. Edits nothing and changes no mode.
