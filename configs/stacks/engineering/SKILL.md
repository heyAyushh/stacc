# Engineering workflow stack

Load only the branch needed for the current task:

- Architecture and design decisions: `improve-codebase-architecture`,
  `grill-with-docs`, or `prototype`.
- Delivery planning: `to-prd`, `to-issues`, or `triage`.
- Tool construction: `mcp-builder`, `cli-for-agents`, or `bash-expert`.
- Skill authoring: `write-a-skill`.
- Release communication: `changelog-generator`.

Read the selected child `SKILL.md`; its completion criteria own that workflow.
